# Fake News Detection Using Machine Learning

## Project Overview
This project aims to detect whether a news article is **Fake or Real** using Machine Learning and Natural Language Processing (NLP).

The system analyzes news text and classifies it based on patterns learned from labeled news data.

## Objectives
- Identify fake and genuine news articles.
- Apply NLP techniques for text preprocessing.
- Train and evaluate multiple Machine Learning algorithms.
- Compare model performance using accuracy and confusion matrices.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas and NumPy
- NLTK
- Scikit-learn
- Matplotlib
- Seaborn

## Machine Learning Algorithms
The following algorithms are implemented:
1. Logistic Regression
2. Naive Bayes
3. Support Vector Machine (SVM)
4. Random Forest
5. AdaBoost
6. Gradient Boosting

## Project Workflow
1. Dataset Collection
2. Data Preprocessing
3. Exploratory Data Analysis
4. Text Cleaning
5. TF-IDF Feature Extraction
6. Model Training and Testing
7. Model Evaluation
8. Hyperparameter Tuning

## Model Accuracy

| Algorithm | Accuracy |
|---|---:|
| Logistic Regression | 97.7% |
| Naive Bayes | 93.7% |
| SVM | 98.6% |
| Random Forest | 99.3% |
| AdaBoost | 99.4% |
| Gradient Boosting | 99.3% |

*These are the recorded results from the notebook's evaluation.*

## How to Run the Project

1. Clone this repository:
   `git clone https://github.com/Raghavi522/Fake-News-Detection-ML.git`

2. Install the required libraries:
   `pip install pandas numpy nltk scikit-learn matplotlib seaborn jupyter`

3. Ensure the required datasets are available and update their file paths if necessary.

4. Open the Jupyter Notebook:
   `jupyter notebook`

5. Run the notebook cells sequentially.
